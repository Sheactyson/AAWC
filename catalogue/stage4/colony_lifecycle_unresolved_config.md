# Stage 4 colony lifecycle unresolved balance configuration

The colony lifecycle uses the established Stage 2 blocker-category overlays as
the only active six-dimensional condition changes. A colony is marked after a
successful exact-packet arrival, remains in colony mode while any native
`obstacle` blocker remains, and leaves that mode once clear without changing
residents, titles, holders, holding types, or restoration state.

The following are deliberately **not authored** in this release candidate:

- a final fully-cleared colony neutrality target;
- separate per-blocker resident-decline coefficients; and
- any additional birth, mortality, capacity, or conversion multiplier.

Those coefficients remain explicit design inputs. The implementation does not
invent them: present blocker decline/recovery is the existing Stage 2
structural-condition contribution path, replayed during the normal Stage 1
monthly lifecycle.
