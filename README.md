# AAWC

Development repository for AGOT Alternate World Compatch.

The repository was initialized from a one-time pre-cleanup safety snapshot on 2026-11-11. Historical 1.10.x.x material that predates Git-per-release history is recoverable from the `pre-cleanup-2026-11-11` tag and its GitHub Release. Pre-1.10 release directories and machine-local CK3 saves were intentionally excluded by user direction.

The post-migration working tree is intended to contain only the current mod source and development tooling. Git commits, tags, and release assets replace the former practice of accumulating a local `versions/` directory.
